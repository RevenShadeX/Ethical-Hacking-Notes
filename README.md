# Ethical Hacking Notes

A personal cybersecurity learning repository documenting practical notes, concepts, exercises, and security-related experiments.

## Overview

The repository is used to organize cybersecurity study material and hands-on learning. Topics include programming fundamentals, web security, SQL injection, CTF practice, and other security concepts.

## Repository Structure

```text
Ethical-Hacking-Notes/
├── Python/          # Python learning and practice
├── PicoCTF/         # CTF notes and solutions
├── SQL-Injection/   # SQL injection learning material
├── README.md        # Repository documentation
└── Other notes      # Additional cybersecurity study material
```

The exact folders and files may change as the learning material grows. Existing notes are preserved.

## Focus Areas

- Cybersecurity fundamentals
- Web security
- CTF practice
- Python
- SQL and database security
- Ethical hacking concepts

## Purpose

This repository demonstrates continuous self-directed cybersecurity learning and provides a record of practical study.
